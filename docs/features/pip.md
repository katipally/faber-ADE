Faber has two picture-in-picture style features.

## Float a tab

The pane header has a Float tab button (shortcut Option F). It lifts that tab into a window of its own that sits above other apps and can be dragged to any display and resized. Press the button again, or Option F, to dock it back.

Details:

- The floating window follows the same text size and look as the main window.
- It can join every Space and sits over full-screen apps.
- Its position and size are remembered, and it is kept on screen if displays change.
- Floating a tab from inside Faber gives it the keyboard; a restored floating tab does not take focus from another app.
- The button is hidden in narrow columns.

## Pop out video

In a browser column, the media controls have a pop out button for the main video on the page. It uses the web's picture-in-picture where the page allows it.
