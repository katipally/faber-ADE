# Changelog

Each release is listed newest first. Downloads are on the [Releases](https://github.com/katipally/faber-ADE/releases) page.

## 1.0.0

First public release.

- Native macOS workspace for coding agents: workspaces, worktrees, columns and tiled panes.
- 22 built-in terminal agents, custom agents and native chat columns.
- Git and pull request tools, including diff review, conflict resolver and stacked PRs.
- libghostty terminals that survive updates.
- Built-in browser and Apps catalog.
- Mods.
- iPhone companion.
- Scheduled agents.
