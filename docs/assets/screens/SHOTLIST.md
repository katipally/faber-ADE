Every image the docs and README reference lives here as `<id>.png`, in this folder. Files marked dropped have no image and no page reference. Capture each one in a throwaway workspace (never a private repo), hide personal data, and save as PNG.

Guidelines: Mac shots at 2x, window about 1400 to 1600 px wide, light or dark but be consistent; iPhone shots from demo mode. Keep each file under 600 KB (pngquant is fine).
